# Órbita

Juego de puzles para navegador, sin dependencias ni compilación. Abre `index.html` directamente o, desde esta carpeta, ejecuta `python3 -m http.server 8000` y abre la dirección del servidor en tu navegador.

Muévete con flechas o WASD. En móvil usa los botones o desliza sobre el tablero. Empuja cajas sobre todos los interruptores, recoge la llave y alcanza la puerta. Puedes deshacer con Z, reiniciar con R y elegir cualquiera de las cinco cámaras. El sonido es opcional y el progreso se guarda localmente cuando el navegador lo permite.

El proyecto original de GameMaker permanece en `../PUZLE IDEA`. Esta versión utiliza gráficos propios dibujados con Canvas. Las fuentes de Google son opcionales; funciona también sin conexión con fuentes del sistema.
